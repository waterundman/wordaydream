## 4. 偏离与未交付项（逐条根因）

### 4.1 S3 de A2/B1/B2 例句回填 = NOT DELIVERED

两条**互相独立**的阻断，任一单独成立即不达标：

1. **覆盖率上界**：唯一被项目裁定允许的「直连 de-zh」路径覆盖率仅 **59.4%**（无任何过滤的理论上界，候选池 39,018）；即使走已被 v1.6.2 SPEC 明确否决的「de→en→zh 二次转译」中转路径（叠加 eng/fra/rus/spa/ita/por 6 语），上界也只到 **62.4%**。两者均 < 80% 目标。priority=1 上界 **80.0%** < 95% 目标。
2. **质量上界**：直连语料下 `matchTier>=2`（仅词干/派生/兜底）弱命中率 **25.4%**，是 N6 上限（10%）的 2.5 倍 —— 德语屈折复杂度超出 `scripts/lib/lemmaForms.mjs` 的规则覆盖，naive join 产出可目视判定的语义错配（`zuvorkommend → "Lass das nicht noch einmal vorkommen!"`、`ausarbeiten → "Ich arbeite."`）。

**根因性质**：不是「语料不可得」，而是「**可得语料的规模上限低于验收线**」。Tatoeba 官方导出实测全部 HTTP 200（`deu_sentences.tsv.bz2` 781,916 句 / `deu-cmn_links.tsv.bz2` 39,023 对 / `cmn_sentences.tsv.bz2` 89,102 句），许可 CC-BY 2.0 FR 允许随应用分发；中文侧 89,102 句总量是结构上限，短期内不会改变结论。

**处置**：按 SPEC §3 S3 的显式条款「不可行时如实 NOT DELIVERED 且 N1 检查保持阻断（缺口可见）」执行 —— 未落盘数据、未写生成脚本、未伪造 `exampleSource`、N1 三个 de 豁免项原样保留。完整证据与复现步骤见 `docs/vault/v1.6.4-DE-EXAMPLE-PROBE.md`。

### 4.2 S4 focus-visible 覆盖率 34/42（规格写 ≥35/42）

**逐项核验结论**：42 个 features CSS 模块中，**只有 34 个模块渲染可聚焦元素**；其余 8 个为纯装饰模块 —— `role="img"`（如 `ProgressRing`）、`aria-hidden`（如 `Dividers`）、纯动画包裹 span（如 `WordUnveilAnimation`）、纯布局/纹理容器等，其内部不存在可 `Tab` 聚焦的交互节点。

即 **34/34 = 100% 的可聚焦模块已覆盖 `focus-visible`**；规格分母（35）与实际不符。**建议**在 SPEC 中把该行改为「**≥34/42（= 100% 可聚焦模块）**」并注明依据（42 个模块中 8 个为纯装饰、无可聚焦元素），而不是写死规则去凑数或给装饰模块加无意义的 `focus-visible` 规则。执行期已在 SPEC §3 S4 加勘误注记，见 §9 执行状态。
