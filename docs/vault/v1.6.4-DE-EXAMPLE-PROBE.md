## 1. 一句话结论

**德语例句语料「可得」，但「不足以达标」——S3 的 ≥80% / priority=1 ≥95% 验收线在 Tatoeba 德语-中文语料上不可达，判定 `NOT DELIVERED`。**

三条硬证据：

1. **可得性**：Tatoeba 官方导出全部 HTTP 200 可下载（`deu_sentences.tsv.bz2` 12.0 MB / 781,916 句；`deu-cmn_links.tsv.bz2` 244 KB / 39,023 对；`cmn_sentences.tsv.bz2` 1.26 MB / 89,102 句），许可 CC-BY 2.0 FR、署名条件明确。
2. **规模上限**：直连 de-zh 语料（唯一被项目裁定允许的路径）对 de A2/B1/B2 的覆盖率**上界 59.4%**（无任何句长/噪声过滤）；即使走已被 v1.6.2 SPEC 明确否决的「de→en→zh 二次转译」路径，上界也只到 **62.4%**。两者都远低于 80%。
3. **质量上限**：直连语料下 `matchTier >= 2`（同根派生/词干兜底）占比 **25.4%**，超过 N6 的 10% 上限 —— 德语屈折复杂度超出 `lemmaForms.mjs` 的规则覆盖，naive join 会产出大量语义错配（实测样本：`zuvorkommend → "Lass das nicht noch einmal vorkommen!"`、`ausarbeiten → "Ich arbeite."`）。

故本轮**不改动任何 `src/data/wordlists/de/*.json`**，**不移除任何 N1 豁免**，`verify-wordlists.mjs` 亦**无需改动**。

#### Q1.2 许可

Tatoeba Terms of Use §6.2 原文：

> "Tatoeba's technical infrastructure uses the default **Creative Commons Attribution 2.0 France license (CC-BY 2.0 FR)** for the use of textual sentences. The BY mention implies a single restriction ... a condition of attribution. That is, using, reusing, modifying and distributing the sentence is only allowed if the name of the author is cited."

§6.5 明确「generally not opposed to using our content for commercial purposes」，但「certain sentences, including those in audio form, cannot be modified」。本轮只用文本句、不改写，故**可随应用分发**，条件是把署名落到数据里。

**CC0 免署名路径不可行（实测）**：`sentences_CC0.csv` 全量 562,200 条里，德语仅 **46 条**、中文仅 **1 条**，de-zh 配对命中 **0 对**。⇒ 必须走 CC-BY 2.0 FR + 署名，与 en 侧口径一致。

### Q3 — 单句体积对包体的影响（风险 R6）

`src/data/wordlists/de/` 现况：`a2.json` 167,885 B / `b1.json` 223,765 B / `b2.json` 354,248 B，合计 **745,898 B**，例句字段为空。

## 3. 覆盖率上限实测（核心证据）

**过滤口径**（与 en 侧 `generate-en-examples.mjs` 同一实现）：译文须含 CJK；排除以 `Tom/Mary/John/...` 开头的 Tatoeba 人名噪声句；句长 ≤ `maxWords` 词；R3 终判用 `scripts/lib/lemmaForms.mjs` 的 `containsLemma`；Top-1 排序为「命中层级 → 句短优先 → id 升序」。词表条目数：a2 797 / b1 1000 / b2 1569 = **3366**；priority=1 共 **441**。

| # | 语料方案 | 候选池 | 覆盖率 | priority=1 覆盖率 |
|---|---|---|---|---|
| A | 直连 deu-cmn，maxWords=12 | 35,923 | **57.2%** (1925/3366) | 77.3% (341/441) |
| A' | 直连 deu-cmn，maxWords=20 | 37,164 | 58.4% (1967/3366) | 78.7% (347/441) |
| A'' | 直连 deu-cmn，无句长过滤 | 37,419 | 59.2% (1991/3366) | 80.0% (353/441) |
| A''' | 直连 deu-cmn，**无任何过滤（理论上界）** | 39,018 | **59.4%** (1998/3366) | **80.0%** (353/441) |
| B | A + 6 语中转（eng/fra/rus/spa/ita/por），maxWords=12 | 66,535 | 61.3% (2062/3366) | 83.0% (366/441) |
| B' | A + 6 语中转，maxWords=20 | 68,577 | **62.4%** (2101/3366) | 84.1% (371/441) |

分级拆解（方案 B，maxWords=12）：`a2` 700/797 = **87.8%**（唯一过 80% 的等级，但其 priority=1 仍不足）；`b1` 707/1000 = **70.7%**；`b2` 655/1569 = **41.7%**。

**弱命中率（N6）**：方案 A 的命中层级为 `base 1332 / inflection 104 / derived 369 / fallback 120`，即 `matchTier >= 2` = **489/1925 = 25.4%**，是 N6 上限（10%）的 2.5 倍。方案 B 为 `460/2039 = 22.6%`，同样超标。样本（语义错配，可直接目视判定）：

```
zuvorkommend  -> "Lass das nicht noch einmal vorkommen!"   | 不要再让这种事发生了！   [tier 2]
Verabschiedung-> "Abschiede sind immer traurig."           | 离别总是让人悲伤。       [tier 2]
ausarbeiten   -> "Ich arbeite."                            | 我工作。                 [tier 2]
abfassen      -> "Fass es nicht an."                       | 别碰它。                 [tier 2]
fundieren     -> "Wo ist das Fundbüro?"                    | 失物招领处在哪儿？       [tier 3]
```

**两条独立的阻断理由**：① 覆盖率上界 59.4%（直连）/ 62.4%（含被否决的中转）< 80%；② 弱命中率 25.4% > 10%。**任一单独成立都足以判定不达标**。

## 4. 许可与署名的残留风险（如实记录）

| 项 | 状态 |

| 默认许可 | CC-BY 2.0 FR，**署名是许可条件**（非可选） |

本轮**未落盘任何数据**，故上述风险**未被引入**。

## 5. 判定与后续建议

### 5.1 判定

**`NOT DELIVERED`**（针对 S3 的 ≥80% / priority=1 ≥95% 验收线）。

- 根因不是「语料不可得」，而是「**可得语料的规模上限低于验收线**」（59.4% vs 80%），且叠加「**德语弱命中率超标**」（25.4% vs 10%）。
- 按 SPEC §3 S3 的显式条款：「不可行时如实 NOT DELIVERED 且 N1 检查保持阻断（缺口可见）」。
- **不伪造 `exampleSource`**：本报告不含任何伪造 id，也未写入任何 `unknown:*`。

### 5.2 保留的豁免项（未改动，逐条列出）

| 1 | N1 | `de/a2.json` | 797（p1 59） | 待 S3 例句回填：该文件零例句语料（覆盖率 0%） |
| 2 | N1 | `de/b1.json` | 1000（p1 67） | 同上 |

### 5.3 后续建议（按优先级）

1. **外部数据供给项（推荐）**：把「de 例句语料」立为**外部数据供给项**，而非工程任务。可选路径与代价：
   - **Tatoeba 全图 BFS**：下载 `links.tar.bz2`（149.9 MB 压缩 / 约 1.1 GB 解压），对 de→cmn 做全图传递闭包（含 2 跳以上）。**预估上限 65–70%**，仍不达标，且引入多跳译文，与 v1.6.2 的「拒绝二次转译」裁定冲突。**不建议**。
   - **扩 `cmn` 语料池**：中文侧总池仅 89,102 句，是硬上限。要突破必须引入**非 Tatoeba** 的 de-zh 平行语料（OPUS 的 OpenSubtitles / TED2020 / WikiMatrix 等）。**但这些语料的许可与质量都需要单独裁定**（NC/SA 条款、字幕碎片句、无标点），且与「教材式短句」的目标不符 —— 属产品决策，不属本阶段。
   - **人工/授权语料**：购买或自建 de-zh 例句库（唯一能同时满足 ≥80% 与质量口径的路径）。
2. **若接受部分回填（需显式批准）**：直连 de-zh 可一次拿到 **57.2%**（1,925 条，+252 KB），把 N1 豁免基线从 `797/1000/1569` 收紧到 `97/293/914`（ratchet 向下，不放宽阈值）。**这需要用户单独裁定**：它既未达 SPEC 的 80% 验收线，也仍会在 N6（弱命中 25.4%）上留缺口。
3. **下一轮 N6 口径补强**：德语弱命中率超标暴露的是 `lemmaForms.mjs` 的**德语屈折覆盖不足**（现有 `IRREGULAR_FORMS` 德语项仅 28 条，其中 9 条是介词融合形式；`STRIP_SUFFIXES` 与英语共用）。这是独立于语料的工程质量缺口，建议单列。

## 6. 复现步骤

```powershell
# 1. 下载 Tatoeba 官方导出 (约 19 MB, 全部 HTTP 200)
$d = 'w:\wordaydream\.tmp-wl\de-tatoeba'; New-Item -ItemType Directory -Force $d
$base = 'https://downloads.tatoeba.org/exports/per_language/'
foreach ($f in @('deu/deu-cmn_links.tsv.bz2','deu/deu_sentences.tsv.bz2','cmn/cmn_sentences.tsv.bz2')) {
  Invoke-WebRequest -Uri ($base + $f) -OutFile (Join-Path $d (Split-Path $f -Leaf)) -UseBasicParsing
}
# 2. 解压 (.bz2 -> .tsv)
python -c "import bz2,os; d=r'$d'; [open(os.path.join(d,f[:-4]),'wb').write(bz2.decompress(open(os.path.join(d,f),'rb').read())) for f in os.listdir(d) if f.endswith('.bz2')]"
# 3. 测量 (临时脚本, 复用 en 侧生成器的 buildIndex/pickExample/collectCandidates 与 lib/lemmaForms.mjs)
node w:\wordaydream\.tmp-wl\de-probe.mjs    # 直连 deu-cmn 覆盖率
node w:\wordaydream\.tmp-wl\de-probe3.mjs   # 句长杠杆 + 上界
node w:\wordaydream\.tmp-wl\de-probe4.mjs   # 6 语中转联合上限
node w:\wordaydream\.tmp-wl\de-probe5.mjs   # CC0 子集规模
node w:\wordaydream\.tmp-wl\de-probe6.mjs   # 修正后上界 + 体积
```

`de-probe*.mjs` 与语料均落在 `.tmp-wl/`（`.gitignore:67`），**不入库**；如需长期保留，应在下一轮把探针脚本纳入 `scripts/`（本轮受「不越域」约束未提交）。
