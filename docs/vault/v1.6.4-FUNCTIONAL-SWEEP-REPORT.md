## 如实留档 (不修, 属产品设计或外部条件)

- **L1 自定义 CSV 词库不参与学习**: `src/data/wordlists/index.ts` 注册了 `custom:csv` loader, 但 `loadWordlist()` 的键是 `${language}:${difficulty}` (`Language` 只有 en/de), 该 loader 按构造不可达; `getAllCsvEntries()` 的生产调用方只有设置面板。要让它参与阅读/复习, 需要设计合并语义 (语言归属、CEFR 映射、导入后缓存失效), 属新功能而非缺陷修复。
- **L2 `#/review` 深链不可达**: `App.tsx` 在 `reviewMode === 'idle'` 时强制回 `#/home` (两处镜像逻辑)。这是状态完整性设计, 但对外暴露的路由地址是死的 —— 若要支持需定义「无会话时是新建复习还是跳课程」。
- **L3 无批量删除 / 清空错词本入口**: `useWrongWordsStore.clearAll` 存在但无 UI, 词表页只有逐行删除。补 UI 属产品决定 (破坏性操作需确认流)。
- **L4 每日目标不可调**: `newWordsTarget` 在 `useWordlistStore` 两处硬编码 10, 只有展示没有 setter, 也没有设置控件。
- **L5 重读/课程完成链在 mock 下无法端到端演练**: `recordLearning` 只在评分 `correct` 时计数, 阈值 `ceil(15*0.5)=8`, 而 `mockProvider` 的 13 个已知词位与 300 个课程目标词零交集, mock 生成也不看 `targetLemmas`。已改用预置 `wordaydream:course` 状态验证模态渲染 (遇到 15 词 / 学会 8 词 / 正确率 80%, 无 NaN, Escape 正确拒绝)。真实链路需接任一真实 provider。
- **L6 观感细节**: 课程页锁定卡在窄屏下的 badge 对比度、离线横幅在「首次进入即离线」后不再复现 (持久化键 `wordaydream-offline-mode` 已消费) —— 未改, 记录待设计确认。
